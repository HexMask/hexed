# KDE Store listing draft

## Name

Hexed

## Summary

A restrained Etched-green hex-cell materialize effect for Plasma 6 windows.

## Description

Hexed reveals normal application windows from their center through a
spreading field of hexagonal cells. When a window closes, the field reverses into a
compact hex disintegration. A brief `#0ee841` edge glow keeps the Etched character
present without turning the desktop into a noisy or high-intensity visual effect.

The effect skips desktop and dock surfaces, menus, tooltips, popups, lock-screen
surfaces, and other special windows. It is designed for Plasma 6 / KWin on Wayland.
